📖 Option d'emprunt de livres

Par défaut, seuls les résidents peuvent emprunter (auto-validé). Activez cette option pour permettre à d'autres membres d'emprunter. Dans ce cas, chaque demande doit être validée par l'admin ou un validateur désigné.

Permettre l'emprunt aux membres (hors résidents)
Les membres ayant le droit "Peut emprunter" verront le bouton 📖 Emprunter dans le catalogue.
● Désactivé
ℹ️ Les membres doivent avoir le champ "Peut emprunter" activé dans leur profil. La demande sera mise en attente de validation par l'admin ou un membre ayant l'accès Validateur d'emprunts (onglet réservé).

Le droit "Peut emprunter" se configure individuellement dans la fiche de chaque membre.
